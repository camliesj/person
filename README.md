## 代码同步

- GitHub 仓库：<https://github.com/camliesj/person>
- 默认分支：`main`
- 同步节奏：Codex 每轮完成修改、执行相应检查后，提交并推送到 GitHub。
- 项目协作约定见 [AGENTS.md](AGENTS.md)，采用 [OpenAI 的项目指引机制](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

该流程在 Codex 执行项目任务时运行；仅在其他编辑器中保存文件不会触发后台上传。

依赖、构建产物及本地环境配置通过 `.gitignore` 排除，环境变量示例可保留在 `.env.example` 中。
