给你的个人空间，添一点新内容。

后台用于更新作品、记录、个人资料和图片。页面布局与样式由代码统一维护。

发布一件作品

  1. 使用 camliesj 的 GitHub 账号登录，选择「作品」并新建。
  2. 填写标题、网址名称、介绍、日期和分类。网址名称使用小写英文与连字符，例如 my-first-project。
  3. 上传封面并填写图片说明。建议使用 JPEG、PNG 或 WebP，单张不超过 5 MB；上传前删除不希望公开的照片信息。
  4. 补充正文和图片。需要在首页展示时打开「在首页精选展示」，并填写顺序。
  5. 保存草稿；准备好后标为待发布，再执行发布。文章会合并到主分支并触发网站构建。
  6. 等待部署成功，再打开正式页面确认。发布不是立即上线；构建失败时，网站仍保留上一版。

草稿与隐藏内容

保存草稿不会更新正式网站。「暂不展示」是额外的隐藏开关，打开时即使已发布也不会出现在网站上。真实作品请关闭「标记为示例内容」。

此项目的 GitHub 仓库公开。草稿分支、上传图片和历史版本也可能被查看，请仅保存准备公开的内容。

更新个人介绍

打开「个人资料与首页」→「网站资料」，修改昵称、简介、首页图片、个人照片与公开联系方式。未填写的邮箱不会显示。

遇到问题

  • 登录未配置：需要先完成 GitHub 登录服务的部署配置。
  • 登录被取消或过期：关闭登录窗口，重新登录。
  • 没有权限：请确认当前账号是 camliesj，并拥有仓库写入权限。
  • 图片上传失败：检查网络与文件大小，保留原图后重试。
  • 发布后未更新：查看 GitHub 中对应提交的 Cloudflare 部署结果；失败时修正内容并重新发布。
